# Vesutil MVP

Чистая стартовая версия Vesutil на Next.js + TypeScript.

## Локальный запуск
Требуется Node.js 20.9+.

```bash
npm install
npm run dev
```

## Railway
Корень репозитория — корень приложения. Build: `npm run build`. Start: `npm run start`. Health check: `/api/health`. Переменные окружения пока не нужны.

## Состав
- Поиск по вторсырью и услугам.
- Категория и местоположение.
- Фильтр «С вывозом».
- Адаптивный интерфейс.

Все карточки и цены — тестовые данные, не реальные коммерческие предложения. Backend, база данных и авторизация пока отсутствуют.
