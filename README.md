# Vesutil MVP

Стартовая версия Vesutil на Next.js + TypeScript.

## Локальный запуск
Требуется Node.js 20.9+.

```bash
npm install
npm run dev
```

## Railway
Корень репозитория — корень приложения. Build: `npm run build`. Start: `npm run start`. Health check: `/api/health`.

## Состав интерфейса
- Поиск по вторсырью и услугам.
- Поиск по названиям, категориям, описаниям и ключевым словам.
- Категории, местоположение, фильтр наличия вывоза.
- Быстрые фильтры и сортировка.
- Адаптивный интерфейс.

## Каталог и модель данных
Начальная схема PostgreSQL находится в `database/migrations/0001_catalog_schema.sql`.

Она включает:
- компании и отдельные филиалы с адресами и координатами;
- категории материалов и услуг;
- справочник материалов и видов услуг;
- предложения филиалов с ценами, единицами измерения, минимальным объёмом и условиями;
- историю версий цен, включая источник Excel-импорта;
- документы к предложениям;
- обезличенные события поисков без результатов для анализа дефицита каталога.

### Важно перед подключением базы
Миграция добавлена в репозиторий, но **не запускалась**. PostgreSQL в Railway не создавался, переменные окружения и платные ресурсы не добавлялись. Перед production-подключением нужно:
1. Согласовать тариф и создать PostgreSQL в аккаунте владельца.
2. Добавить серверный слой доступа к БД и миграционный процесс.
3. Настроить авторизацию и разграничение доступа (включая защиту кабинетов компаний).
4. Добавить проверку входных данных, аудит изменений прайсов, резервное копирование и политику хранения файлов.
5. Проверить миграции на отдельной тестовой базе.

## Демонстрационные данные
Карточки интерфейса и цены — тестовые данные, не реальные коммерческие предложения. Не использовать их как фактические цены рынка.


## Каталог API

- `GET /api/catalog/categories` — список категорий; необязательный параметр `kind=material|service`.
- `GET /api/catalog/offers` — предложения; параметры: `kind=material|service`, `q`, `category`, `city`, `pickup=true|false`.

Ответы содержат `data` и `meta`. Пока источник явно помечен как `demo`; репозиторий каталога изолирован от API, чтобы позднее заменить демонстрационный источник на PostgreSQL без переписывания интерфейса.
